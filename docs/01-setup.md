# 一、配置流程

## 1. AI agent 里的 "agent" 是什么意思

agent 是**智能体**的意思。平时大家用的手机端豆包、DeepSeek，不属于智能体，属于"对话"式的 AI。

今天想介绍的是 AI agent 智能体。豆包和 DeepSeek 桌面端属于对话工具；而 agent 会**拆解任务、调用工具、检查结果，并反复迭代**。

说人话就是：他能帮你直接操作电脑去完成任务，而不仅限于给你方法。

## 2. DeepSeek Harness 的下载

- DSH 下载：<https://deepseek.com/harness/>
- 建议一起开的：API 开放平台 <https://platform.deepseek.com/>

## 3. Codex 与 CC Switch 的下载

- Codex：直接到微软商店下载
- CC Switch：安装包已经准备好了（见分享会现场）

## 4. API Key 的配置

以机器人来举例：智能机器人不仅要有手臂这些外设条件，还要有"脑子"。

- Codex 和 Harness 是会调用工具的智能体，相当于机械臂，能够调用工具；
- API Key 相当于"钥匙"，这把钥匙让 Codex 和 Harness 远程连上"脑子"，这样就可以调用工具。

> ⚠️ **API Key 不能给别人看到**，也最好不要发给 agent 让它帮你记住，否则会有风险。
> （例如别人拿了你家的钥匙偷你家钱。）如果别人拿到了这个 API Key 远程接到自己的 agent 上，你的 💰 就被偷走了。

- **CC Switch**：让 agent 的"脑子"顺利接入智能体的工具；
- **DeepSeek Harness** 不用接入，下载之后就已经自动通过账号链接好了；
- **Codex** 需要配置一些文件（现场演示）。

### 如果想用 GPT，有两种方法

1. 搞到一个海外账号，借助一些方式购买会员；
2. 通过中转站来获取 API Key（但会导致被骗之类的）。

且这两种方法都需要"科学上网"，不好教授，且都不稳定（买会员有被骗的风险，中转站也不一定是纯 GPT，有可能注水）。
