# 三、Codex 的使用，以及与 DSH 的差别

## 1. Codex 的使用

建议可以多连一连各种模型的 API 来使用：豆包、千问、GPT、DeepSeek、Kimi 都可以试着用一下（不过对于大多数场景我推荐 DeepSeek，便宜好用）。

## 2. Codex 适合什么

Codex 这个软件，对于**课堂问答**比较方便一些。如果你用 DeepSeek，你会发现有时候你本来只是简单想提个问题，但是它直接给你输出了文档。

## 3. Codex 与 DSH 的差别

- **Codex** 可以理解为已经组装好的**商品房**，想要改变流程可能比较困难；
- **DSH** 可以理解为有一定基础的**毛坯房**，怎么装修、怎么摆家具都可以你自己 DIY。
