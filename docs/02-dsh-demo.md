# 二、以 DSH 为例：agent 怎么用

## 1. 提示词（prompt）

提示词就是让 AI 能够明白你要做什么的话语。**提示词越丰富，agent 就不用去"猜"你想干什么。**

你给 AI 指派了一个任务，那么 AI 一定是趋向于返回给你结果的。如果你没说清楚你想干什么，那它只会以"它认为"的方式来完成任务，就会导致结果可能不符合预期。

## 2. 如何写好提示词 / 让 agent 精确干活

最好的方法：**让 agent 倒回来问你问题，让你做选择题。**

> 示例：
> 马上考试了，老师的课件在这里，帮我整理一份知识点，每个知识点配一道例题，并给出答案。其中如果有任何疑问可以直接发几个问题给我，例如答案格式 / 题目难度等等。

## 3. 四种模式

| 模式 | 适合做什么 |
| --- | --- |
| **默认模式** | 写代码、改项目 |
| **PTC 模式** | 连续调用工具（去浏览器搜索、帮你操作和截图等等）。主要在多技能调用上有优势，省钱、速度快 |
| **创造模式** | 开发插件和模式 |
| **极简模式** | 不推荐 |

**创造模式展开：**

- **插件**：使页面变得好看、方便用户来调用工具；
- **模式**：将一套流程简化为一个模式。

  > 例如：问问题 + 根据问题生成 md 文件 + 检查 + 开始动手干活。
  >
  > 贴近生活的例子——帮我完成这个实验报告：
  > 1. 文件里有要求的参考内容；
  > 2. 对于开始做实验报告有疑问的地方，可以直接发选择题给我；
  > 3. 选择完之后生成 md 文件；
  > 4. 根据 md 文件（我审查没问题后）开工。

## 4. 智能体团队

手动输入提示词，说明我需要调用哪些插件、哪些模式。

比如我要做一个自媒体视频：

- 我需要一个出稿人；
- PPT / 视频技术专家……
