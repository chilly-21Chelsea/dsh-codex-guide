# 四、DeepSeek Harness 使用要点

## 1. 输入 `/` 可以选择模式

- **计划模式**：可以问你问题，帮助你进行计划；
- **目标模式**：可以朝着一个目标做，直到结束（注意要明确需求）。

## 2. 输入 `@` 可以调用文件与会话

输入 `@` 可以把对应的文件和会话调用进来。

## 3. 让 AI 先加载 md 文件

**md 文件是什么？** 一种纯文本格式的文档，人和 AI 都容易读写、便于检查。

推荐流程：**先检查已有资料，生成 md 文件，等我确定再开始。**

这套流程「问问题 + 根据问题生成 md 文件 + 检查 + 开始动手干活」可以用**创造模式**进行复用。

> 举个例子：我现在正在学高等数学，我需要你帮助我总结。

## 4. 四种模式

| 模式 | 适合做什么 |
| --- | --- |
| **默认模式** | 写代码、改项目 |
| **PTC 模式** | 连续调用工具（去浏览器搜索、帮你操作和截图等等）。主要在多技能调用上有优势，省钱、速度快 |
| **创造模式** | 开发插件和模式 |
| **极简模式** | 不推荐 |

**创造模式展开：**

- **插件**：使页面变得好看、方便用户来调用工具；
- **模式**：将一套流程简化为一个模式。

  > 例如：问问题 + 根据问题生成 md 文件 + 检查 + 开始动手干活。
  >
  > 贴近生活的例子——帮我完成这个实验报告：
  > 1. 文件里有要求的参考内容；
  > 2. 对于开始做实验报告有疑问的地方，可以直接发选择题给我；
  > 3. 选择完之后生成 md 文件；
  > 4. 根据 md 文件（我审查没问题后）开工。

## 5. 智能体团队

手动输入提示词，说明我需要调用哪些插件、哪些模式。

比如我要做一个自媒体视频：

- 我需要一个出稿人；
- PPT / 视频技术专家……

（例子可能不好，大家理解意思就行。）
